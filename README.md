## Description

A re-implementation of the C standard library `printf` function. The goal is to produce a `libftprintf.a` static library exposing `ft_printf`, which handles the conversion specifiers `%c`, `%s`, `%p`, `%d`, `%i`, `%u`, `%x`, `%X`, and `%%`.

## Instructions

```bash
make
make clean
make fclean
make re
```

Link the library when compiling your own project:
```bash
cc main.c -L. -lftprintf -o program
```

## Algorithm & Data Structure

The format string is iterated character by character. When a `%` is encountered the next character selects the conversion handler via a simple `if/else` chain. Each handler receives the `va_list` and returns the number of bytes written, which are accumulated for the final return value. No heap allocation or extra data structure is needed because each specifier is dispatched and handled in one function call.

This approach was chosen for its simplicity and strict norm compliance: O(n) time over the format string, O(1) auxiliary space, no dynamic memory, and each conversion is isolated in its own function making the code easy to read and extend.
